# Doc 骨架說明

**Apps Script 的 `initDoc()` 會自動幫你建好下面 6 個 Heading 1**，你不用手動貼。但如果想自己先在 Doc 開頭加個封面、目錄之類的，記得放在這 6 個 H1 *之前*。

## 6 個必要的 Heading 1（文字必須完全一致）

```
1. 主幹專案 (TRUNKS)
2. 留言泡泡 (NODES)
3. 每日進度 (DAILY_REPORTS)
4. 標註紀錄 (MENTIONS)
5. 成員 (MEMBERS)
6. 資料字典
```

每個 H1 之間的內容會被 Apps Script **完整覆蓋**（從該 H1 的下一行開始，到下一個 H1 之前）。

## 你可以在 Doc 裡保留不被覆蓋的東西

放在「第一個 H1 之前」的內容永遠不會被動到。建議結構：

```
[Doc 標題（不是 H1，是純文字或 Title 樣式）]
[更新時間說明、目錄、組員備註... 都隨便]

# 1. 主幹專案 (TRUNKS)
（這裡的所有內容會被每次同步覆蓋）

# 2. 留言泡泡 (NODES)
（會被覆蓋）

...
```

## 字型與樣式建議

- 章節 H1 都用 Google Doc 預設的「標題 1」樣式
- Apps Script 會自動將子標寫成「標題 2 / 標題 3」、把表頭加底色
- 想換字型/顏色，直接在 Doc 的「樣式」設定一次即可，新寫入的段落會繼承樣式
